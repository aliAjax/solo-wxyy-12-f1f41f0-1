# 钟乳石洞穴微环境巡测

围绕洞穴样点与巡测记录，补全「异常发现 → 自动分级 → 待办接力 → 复查销项」的完整闭环。

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912 ，数据保存在 `data/db.json`。

## 闭环说明

1. **保存巡测，自动分级**：按所选样点的四项基准（温度、湿度、CO₂、滴水频率）与本次实测值逐项比对，
   偏差达到「中/高」阈值即记中/高风险，多项异常取最高等级；填写了游客干扰痕迹至少记中风险。
2. **异常只生成一份待办**：分级异常时，巡测与待办在**同一次原子写入**中落库；同一条巡测永远只挂一份待办。
3. **两人接力**：巡测员领取 → 现场处理并提交复查 → **另一名**复查员复核，通过则销项（巡测同步标记已复查），
   不通过则驳回，退回原处理人继续处理，可反复往返。
4. **不重复流转 / 防越权**：
   - 前端每次操作带 `clientToken`，同一请求重放返回首次结果（幂等）；
   - 同人同天同样点重复登记、他人重复领取、复查中重复提交均被拒绝（409）；
   - 巡测员不能领取他人待办或销项，复查员不能领取/处理，处理人不能给自己销项（403）；
   - 待办与巡测的通用 PATCH/DELETE 入口已封闭，只能走状态机端点。
5. **处理时限与自动升级**：中/高风险与复查环节各有时限（管理员可调），超时在读/写路径自动升级、
   时限顺延、样点联动暂停开放，每次升级写入审计轨迹。
6. **审计轨迹**：待办每一步（发现/领取/提交/驳回/销项/升级）都记录操作人、时间与说明，页面可展开查看；
   样点与巡测保留历史记录。
7. **中断恢复 / 不留半成品**：
   - 存储采用「写临时文件 + rename」原子替换，写入失败自动清理临时文件，原数据字节不变；
   - 所有读-改-写事务串行执行，并发领取只有一人成功；
   - 启动时自动迁移：为历史异常巡测补建缺失待办、补分级、清理残留临时文件。
8. **判定规则管理员可调**：「判定规则」页（仅管理员可见）调整四项指标的中/高偏差阈值、各环节时限、
   干扰痕迹是否计风险，调整即时生效且留痕。

## 页面

- **趋势看板**：统计卡片 + 临近时限的未结待办
- **复查待办**：待处理 / 与我相关 / 已销项；卡片上领取、提交复查、驳回、销项，可展开完整轨迹
- **样点档案 / 巡测记录**：原有入口照常使用（样点新增第四项基准「基准滴水」）
- **判定规则**：管理员专属

右上角可切换当前操作身份（管理员 / 巡测员 / 复查员），用于演示角色权限。

## 端到端验证

```bash
node e2e-test.js    # 主流程与边界：分级、幂等、越权、驳回、销项、升级、规则
node e2e-race.js    # 并发领取/提交竞态
node e2e-atomic.js  # 写入失败不留半成品（需对 data 目录有 chmod 权限）
```
